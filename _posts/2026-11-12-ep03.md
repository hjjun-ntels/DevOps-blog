## 2. Docker Hub

Docker Hub는 Docker 이미지를 저장하고 배포하는 레지스트리다.

공개 Docker Hub에서 이미지를 직접 내려받으려면 해당 서비스에 네트워크로 접근할 수 있어야 한다. (외부망 연결 필요)

**컨테이너를 실행할 때마다 인터넷이 필요한 것은 아니다.**

이미지가 로컬에 남아있거나, 외부망이 안될때는 사내 Registry 사용해서 다운받을 수 있다.

### image donwnload command 
```bash
# 외부망(인터넷) 접속 가능 환경
 docker pull hello-world:latest
 docker save -o hello-world.tar hello-world:latest

# tar등 파일로 image를 업로드한 경우
 docker load -i hello-world.tar
```

## 3. Docker Engine install

### 3.1 Docker 공식 Repository 등록

우선 외부망 연결을 위해 DNS 설정을 해줌.
/etc/resolv.conf 에 1.1.1.1 등록
(다행히 사내서버에서 인터넷으로 나갈 수 있음)

```bash
dnf install -y dnf-plugins-core

dnf config-manager --add-repo \
  https://download.docker.com/linux/rhel/docker-ce.repo
```


### 3.2 Docker 패키지 설치

```bash
dnf install -y \
  docker-ce \
  docker-ce-cli \
  containerd.io \
  docker-buildx-plugin \
  docker-compose-plugin
```

버전은 아래와 같다

```text
Docker version 29.9.3, build 5457199
Docker Compose version v5.7.1
```

### 3.4 Docker 서비스 시작

```bash
systemctl enable --now docker
systemctl status docker
```


## 4. 첫 번째 컨테이너 실행: hello-world

국룰 hello world

```bash
docker run --rm hello-world
```

최초 실행에는 로컬에 이미지가 없어서 허브에서 다운받는다는 메시지 출력됨.

```text
Unable to find image 'hello-world:latest' locally
latest: Pulling from library/hello-world
4f55086f7dd0: Pull complete
d5e71e642bf5: Download complete
Status: Downloaded newer image for hello-world:latest
```

다운 받고 컨테이너가 실행됨

```text
Hello from Docker!
This message shows that your installation appears to be working correctly.
```

### 4.1 동작 과정?

1. Docker CLI (`docker`)가 Docker Daemon(`dockerd`)에 실행을 요청
2. Daemon이 로컬에 `hello-world:latest` 이미지가 있는지 확인
3. 이미지가 없으므로 Docker Hub에서 다운로드
4. 이미지를 바탕으로 컨테이너를 생성
5. containerd와 OCI 런타임이 컨테이너 내부 프로그램을 실행
6. 프로그램의 출력문 출력
7. 프로그램 종료 후 `--rm` 옵션에 따라 컨테이너가 자동 삭제

★ **`Hello from Docker!`는 Docker Daemon 자체의 출력이 아니라 컨테이너 안의 프로그램이 출력한 메시지**

## 5. 이미지로 컨테이너 생성해 보기

방금은 이제 image 다운로드 -> 컨테이너 생성 -> 컨테이너 삭제 였다면,
이제는 이미 다운로드 된 이미지로 컨테이너 생성해볼거임

### 5.1 이미지 확인

```bash
docker images
```

`hello-world:latest`가 로컬에 남아 있는지 확인

### 5.2 컨테이너 생성

```bash
docker create --name hello-test hello-world:latest
docker ps -a
```

`docker create`는 컨테이너를 **생성만** 한다. 실행 전이므로 상태는 `Created`다.

### 5.3 컨테이너 시작

```bash
docker start -a hello-test
docker ps -a
```

`-a` 옵션으로 출력에 연결하면 다시 `Hello from Docker!`를 볼 수 있다.

`hello-world` 프로그램 자체는 메시지를 출력하고 종료하므로 이후 상태는 보통 `Exited (0)`이 된다.

### 5.4 컨테이너 삭제

```bash
docker rm hello-test
docker images
```

컨테이너를 삭제해도 원본 이미지는 삭제 안됨.

| 명령어 | 역할 |
|---|---|
| `docker pull` | 이미지 다운로드 |
| `docker create` | 이미지 기반 컨테이너 생성(시작하지 않음) |
| `docker start` | 생성된 컨테이너 시작 |
| `docker run` | 필요 시 이미지 다운로드 후 컨테이너 생성 및 시작 |
| `docker ps -a` | 종료된 컨테이너까지 포함해 상태 확인 |
| `docker rm` | 컨테이너 삭제 |

### 5.5 컨테이너 이름 랜덤 생성

이건 뭐 중요한 건 아닌 것 같은데, 

```bash
docker run hello-world:latest
```

이렇게 실행해보니, 랜덤한 이름으로 된 컨테이너가 생성되었다.

```text
[root@hanju-playground samsung]# docker ps -a
CONTAINER ID   IMAGE                COMMAND    CREATED         STATUS                     PORTS     NAMES
5c7cc260b0b3   hello-world:latest   "/hello"   2 seconds ago   Exited (0) 2 seconds ago             naughty_mcclintock
a4461cb3ff76   hello-world:latest   "/hello"   9 seconds ago   Exited (0) 9 seconds ago             competent_leakey
```
