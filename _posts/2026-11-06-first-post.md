## Prologue

ESN 프로젝트가 끝나간다.

ESN은 VNF 기반의 환경이었고, 다음 프로젝트가 뭐가 될지 모르겠지만, CNF 기반으로 될 것 같다는 예고를 받았다.

마침 컨테이너 / Kubernetes 등 클라우드 기술을 공부하려 했는데 마침 잘됐다.

공부해보자.

## TODO

이 블로그에는 다음과 같은 내용을 기록하려고 한다.

1. Container & Orchestration
    - Docker — 컨테이너 개념 및 이미지 생성, 관리
    - Kubernetes — 컨테이너 오케스트레이션 및 서비스 운영

2. Cloud & Infrastructure as Code
    - AWS — 클라우드 인프라 구축 및 운영
    - Terraform — IaC(Infrastructure as Code)를 활용한 인프라 자동화

3. CI/CD & Automation
    - GitHub Actions — CI/CD 파이프라인 구축
    - CI/CD — 빌드, 테스트, 배포 자동화

4. Monitoring & Observability
    - Prometheus — 메트릭 수집 및 모니터링
    - Grafana — 모니터링 데이터 시각화 및 대시보드 구성

## Goal

Docker부터 시작해서 Kubernetes, AWS, Terraform, CI/CD, 모니터링까지 하나씩 공부해 볼 생각이다.

최대한 빠르게 그리고 딥하게 공부하고싶지만 일이랑 병행하면서 얼마나 시간을 투자할 수 있을지 모르겠다.

그래도 일단 해보자.
